Privacidad y copias de seguridad

Las prendas y fotografías se guardan automáticamente en este dispositivo al pulsar «Guardar prenda». No tienes que exportar e importar para usar la app cada día. La aplicación no las envía a GitHub ni a ningún servidor.

Comprobando la protección del almacenamiento…

Guarda una copia periódicamente. Si borras los datos de Safari o del sitio, podrías perder las prendas guardadas. El archivo de copia contiene tus fotos y datos: guárdalo en un lugar privado.

Cómo funciona

Las sugerencias usan reglas locales de categoría, color, estilo y temporada. No se usa IA en la nube ni se envían tus datos personales.
